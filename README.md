## Важно

Это архив расчётных листов для ознакомления и обучения. Результаты не проверялись для применения в реальном проектировании; перед использованием перепроверьте формулы, исходные данные, единицы измерения и актуальность нормативов. Наличие файла в репозитории не означает сертификацию расчёта.

Файлы не лицензированы для повторного использования. Сведения об авторстве и правах на распространение следует уточнить отдельно.
